## Version History

### Version Numbering

Windows Toolbox follows Semantic Versioning:

- **Major** (1.x.x): Breaking changes, major new features
- **Minor** (x.1.x): New features, backward compatible
- **Patch** (x.x.1): Bug fixes, minor improvements

### Release Channels

- **Stable**: Fully tested releases (recommended)
- **Beta**: Preview of upcoming features (may have bugs)
- **Dev**: Cutting-edge features (unstable)

## How to Update

Windows Toolbox automatically checks for updates on startup. You can also:

1. Open Settings → About
2. Click "Check for updates"
3. Follow the prompts to download and install

Or download manually from [GitHub Releases](https://github.com/rich-wisdom/Toolbox/releases).

## Upgrade Notes

### From Pre-Release to 1.0.0

If you're upgrading from a pre-release version:

1. Uninstall the old version
2. Install the new MSIX package
3. Your settings and preferences will be migrated automatically
